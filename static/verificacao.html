Verificação e API pública

Transparência · Dados abertos · Sem autenticação
Este site é independente e republica dados públicos do TSE. Qualquer pessoa pode conferir os números abertamente — sem login, sem token, sem app. Os links abaixo apontam direto para a API deste site, que por sua vez busca no resultados.tse.jus.br. Cada resposta inclui um hash SHA-256 do JSON bruto do TSE, permitindo verificar que o número mostrado aqui bate byte-a-byte com o que o TSE publicou.

Saúde do sistema

GET /health
Verifica se o app está no ar e se o banco está conectado. Retorna {"ok": true} em condições normais.
GET /api/config-publica
Mostra os códigos de eleição do TSE que este site está usando (eleicao_cod_1t presidente, eleicao_cod_1t_estadual governador/senador/deputados). Permite auditar que estamos apontando pros pleitos corretos.

Catálogos

GET /api/cargos
Lista todos os cargos em disputa (presidente, governador, senador, dep. federal, dep. estadual) com código TSE correspondente.
GET /api/ufs
Lista as 27 unidades federativas + BR (agregado nacional).
GET /api/candidatos?cargo=1
Candidatos de um cargo (aqui, presidente). Para outros cargos passe cargo=3 (governador), 5 (senador), 6 (dep. federal), 7 (dep. estadual) e opcionalmente uf=SP.

Apuração ao vivo

GET /api/apuracao/atual?cargo=1&abrangencia=BR
Snapshot mais recente da apuração — votos totais, candidatos ordenados, % apurado, hash SHA-256 do JSON bruto do TSE para verificação. Troque cargo e abrangencia para outros cortes (ex.: cargo=3&abrangencia=SP pra governador de SP).
GET /api/apuracao/historico?cargo=1&abrangencia=BR&candidatos=<sqs>
Série temporal dos últimos snapshots (até 200 por chave) para os candidatos indicados. Parâmetro candidatos é obrigatório — lista de sq_candidato separada por vírgula (ex.: dois candidatos do exemplo). Pegue os sq_candidato em /api/candidatos?cargo=1. Permite reconstruir a curva de evolução da apuração no dia D.
GET /api/apuracao/proporcional?cargo=6&uf=SP
Simulação do cálculo proporcional (quociente eleitoral, barreira de 10%, sobras em 3 fases) com os dados atuais. Só faz sentido para cargo=6 (dep. federal) ou cargo=7 (dep. estadual).
GET /api/eventos?cargo=1&abrangencia=BR
Eventos matemáticos registrados: candidatos eleitos no 1º turno, 2º turno definido, viradas, candidatos matematicamente eliminados.

Drill-down (município e zona)

GET /api/apuracao/lideres-por-uf?cargo=1
Líder em cada uma das 27 UFs — para o mapa nacional.
GET /api/apuracao/lideres-por-municipio?cargo=3&uf=SP
Líder em cada município de uma UF (vindo do próprio snapshot estadual que o TSE já traz com breakdown por município).
GET /api/apuracao/municipio-tse?uf=SP&municipio=71099&cargo=3&turno=1
Puxa a apuração de um município direto do TSE (busca ao vivo, cache de 45s). Útil quando o breakdown do snapshot estadual não traz detalhes suficientes.
GET /api/apuracao/bu?uf=SP&municipio=71099&zona=1&secao=1&cargo=1&turno=1
Boletim de urna de uma seção específica. Inclui URL da imagem JPEG assinada digitalmente pelo TSE (verificação criptográfica possível). Interface amigável em /urna. Cache 5min, sem persistir no banco.

Páginas do site

GET /
Placar principal da apuração.
GET /sobre
Sobre o projeto, FAQ, termos de uso e política de privacidade.
Nota sobre endpoints administrativos. Endpoints sob /api/admin/* existem para operações reservadas (importar candidatos manualmente, limpar seed de teste, disparar sincronização). Eles exigem token (X-Admin-Token) e por isso não aparecem aqui — não há nada que uma pessoa comum do público precise fazer com eles. A página /importar também cai nessa categoria: o formulário existe mas só funciona com o token de admin.
